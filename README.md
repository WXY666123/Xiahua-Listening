# 虾滑雅思听力网页版

由桌面版转换的 iPad Safari 网页版。题库、音频、套题练习、计时、作答记录和解析均在浏览器中运行。

练习记录保存在当前浏览器。清除 Safari 网站数据会删除本机记录。
## 2026-09-23 稳定性修复

- 返回题库统一使用站点根路径。首页与播放器外壳首次联网缓存成功后，导航断网、HTTP 错误或超过 3.5 秒时回退到缓存；不缓存音频，不改变浏览器原生 Range 请求。
- 单篇和套题共用音频恢复逻辑：保留位置与倍速、最多自动重试 3 次；切后台暂停，返回后由用户点击播放。新增“恢复声音”按钮，可重新连接媒体而不用退出题目。
- 不更换答题记录存储键，不删除历史记录。缓存仅清理本网站旧版 `xiahua-shell-*`，不触碰其他网站缓存。
- 验证：`node --test scripts/test-recovery.cjs scripts/test-site-cache.cjs`；修改脚本的 `node --check`；`git diff --check`。
- 本地浏览器验证：普通题播放、恢复后进度保留；套题播放至 23 秒后恢复声音保持进度并继续播放，模拟断网返回题库显示 130 篇。iPad 实际声道中断尚未复现，需设备验收。缓存首次建立前仍依赖网络；不承诺全部题目和音频离线可用。
- 发布范围：根目录 `index.html`、`sw.js` 与修改/新增的 `JS/` 文件。发布版本：20260923b。
