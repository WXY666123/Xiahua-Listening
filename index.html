Guide

新手必看（使用前一定看）

iPad 直接用 Safari 打开本站即可练习，无需安装软件，也不需要电脑保持开机。答题记录保存在当前浏览器中，换设备或清除 Safari 网站数据前请先导出记录。

先看这几条，很重要

  • 推荐在 Safari 中打开，并用“分享 → 添加到主屏幕”保存为桌面图标。
  • 题库、题目、音频和 PDF 已内置到网页，不需要选择本地文件夹。
  • 同一台 iPad、同一个 Safari 会自动保留进度；无痕浏览不适合长期练习。
  • 换 iPad、换浏览器或清空全部记录前，先点左侧“保存答题记录”。
  • Clear 只清当前这次作答，不会删除历史记录；“清空全部做题记录”才会删除记录。
  • 资料仅供练习和参考，不提供也不承诺预测。
VIP 与资料说明
VIP版和普通版有什么区别？

VIP 价格为 49 元 / 一次性。主要包含：

  • 90 篇额外题目，其中包括约 30 篇地图、5 篇装置图、3 篇流程图、5 篇非常规题型。
  • 149 个带练视频，单个视频约 12-22 分钟，适合模仿复盘和系统学习。
  • 永久答疑、经验分享，以及更频繁的高低频更新。
  • 和语料库一起购买可立减 30 元。
VIP 授权怎么理解？

未解锁时可以使用普通题。输入有效授权码后，VIP 题库会在授权期内可用；授权码只在规定时间内可用，激活成功后 VIP 固定可用 7 天，到期后需要输入新的授权码。

解锁步骤：点击左边侧栏的 解锁 VIP，输入 VIP 授权码即可；授权码在群文件里，每周会更新。

能不能预测？

不能，不能，不能。资料仅供练习和参考，不承诺预测命中，也无法告知更具体的地区或时间。

请不要相信或购买任何“预测”。真正稳定的提升，还是来自练习、复盘和能力本身。

能不能多出一点，或者一次性出完？

暂时不能。题目和音频制作都需要反复测试，数量已经不少，但我一个人的精力有限，还需要维护产品、VIP 内容和其他事情。会继续更新，但无法一次性全部做完。

纸笔可以用吗？海外可以用吗？

可以。它本质是练习素材，纸笔、机考、海外都可以作为补充练习使用。但不要完全依赖它，剑雅依然是不可替代的基础素材。

海外题目也会轮换出现，只是不同地区考题不一定完全一致。心态上当作练习就好。

iPad 网页版使用
iPad 怎么打开？
  1. 用 Safari 打开网页版链接。
  2. 等待首页显示“普通 / 130篇”，然后选择题目开始练习。
  3. 需要桌面图标时，点 Safari 的“分享 → 添加到主屏幕”。
需要安装软件吗？

不需要。网页版在 Safari 内运行，不使用 Windows 的 xiahua.exe 或 Electron 运行时。

使用时需要电脑开机吗？

不需要。发布完成后，iPad 可以独立访问网站；只要能连接互联网即可。

需要 VPN 吗？

通常不需要。校园网或手机热点能正常访问网页链接时即可使用。

网页打不开或音频不播放怎么办？

先刷新页面，并确认 Safari 能正常访问 GitHub Pages。音频需要点播放按钮后才会开始；若校园网限制访问，可临时切换手机热点。

题库与答题记录
题库怎么更新？

网页版题库由网站统一更新。重新打开或刷新网页即可获取已发布的版本，不需要在 iPad 上解压或移动文件。

为什么首页没有显示 130 篇？

先清空搜索框和筛选条件；筛选数字会随当前条件变化。如果仍显示 0 篇，请刷新页面或切换一次网络。

题目或音频加载失败怎么办？

刷新当前页面后重试。校园网偶尔会限制或缓存 GitHub Pages 资源，此时可以切换手机热点；正常使用不要求 VPN。

答题记录保存在哪里？

答题记录保存在当前 Safari 的网站数据中。清除 Safari 历史记录与网站数据可能会删除它，请定期使用左侧“保存答题记录”导出 JSON 备份。

换电脑或更新版本前要做什么？

建议先点击左侧“保存答题记录”导出 JSON。新版本或新电脑里点击“导入答题记录”即可恢复。

导出/导入用于迁移做题记录、错题记录、套题记录、笔记和高亮等答题数据。

Clear、Finish、套题记录有什么区别？
  • Finish / Next 会保存当前答题内容；做到一半退出后，待完成记录会尽量保留，重新进入可继续。
  • Clear 只清空当前页面的作答痕迹，不会删除已经进入错题本和历史里的记录。
  • 清空全部做题记录会删除正确率、错题本、套题记录和待完成草稿；操作前建议先导出备份。
  • 单篇题目可以自由调整倍速；套题做题时会更接近考场状态，音频控制会受到限制，回看时可以操作。
功能说明与注意事项
首页题库列表可以做什么？

首页会展示普通题和 VIP 题，并按 Part、频次、题型和完成状态筛选。也可以用搜索框按题号、标题或关键词查找题目。

如果刚更新网站后没有显示，请刷新页面；仍未更新时可关闭标签页后重新打开。

未做、待完成、已完成分别是什么意思？
  • 未做：没有正式提交记录，也没有保存中的草稿。
  • 待完成：已经开始作答但还没有 Finish，首页会优先显示当前草稿进度。
  • 已完成：已经 Finish 过，首页显示最近一次正式成绩；如果又开始了一次新草稿，会同时提示待完成进度和上次成绩。

直接退出不会等于重新提交；只有 Finish / 套题最后提交才会生成正式成绩。

单篇练习有哪些功能？
  • 可以做题、提交、查看结果和回看解析。
  • 可以使用原文和精听、听写模式、笔记和高亮。
  • 单篇音频可以自行调整倍速。
  • 从首页点开题目时，会比较单篇草稿和最近一次正式记录的时间：较新的草稿会继续作答，否则回看最近一次记录。
  • 最近记录可能来自单篇，也可能来自套题；如需从空白开始，在回看页面点击 Clear 即可，原历史不会删除。
套题匹配是做什么的？

套题匹配会随机组成 P1-P4 一整套题，并按雅思听力 40 题的分数表估分。频率选项表示优先偏好；首选频率没有新题时，会从另外两种频率的新题中随机。

VIP 解锁后可以选择全部题库、仅普通或仅 VIP。所选范围内全部新题用完后，才会按错题情况兜底抽取历史题。

每次随机前会快速核对完整题库索引；题库没变化时直接使用完整缓存，检测到新增、移动或删除时才更新候选池。

已经出现在套题历史里的 Part 会优先避开，包括未完成套题；只要范围内还有新题，就不会回抽已练题或错题。

套题做题时更接近考场状态，音频控制会受到限制；回看时可以操作音频，“查看解析”会定位到对应题目的解析和最新音频时间点。

套题里的 Next、Previous、Finish 怎么用？
  • Next：进入下一 Part，并保存当前 Part 的作答。
  • Previous：回到上一 Part，继续查看或修改。
  • Finish：最后一 Part 完成后提交整套，并生成整套结果。
  • 做到一半退出时，待完成草稿会尽量保留，下次可以继续。
错题本会记录什么？

错题本会记录单篇和套题中做错的题，并保留最近几次对应记录。点“回看这次”会打开对应那一次的界面，不是最新一次。

如果从错题本选择“重做这篇”，会重新空白开始；如果只是回看，不会新增记录。

原文和精听怎么用？

单篇练习里可以打开原文和精听，进行逐句播放、循环、慢速、显示中文、显示解析和听写模式。

套题做题过程中通常不能打开原文和精听，避免影响模拟考试状态；套题回看时可以查看。

原文主要来自 AI 识别和人工整理，可能有少量小错误，以题目 PDF 和实际音频为准。

高亮和笔记有什么注意事项？

高亮和笔记会随答题记录保存，用于复盘和回看。建议高亮关键词或短语，不要大范围跨行选中，以免影响页面排版。

如果想重新做题，可以使用 Clear 清空当前作答痕迹；这不会删除已经保存的历史记录。

为什么重新进入题目还会看到答案或高亮？

这是为了保留上一次作答现场，方便继续做题或复盘。单篇、套题回看和错题本都会尽量恢复当时的答案、高亮和笔记。

如果想从空白重新开始，请点击当前题目里的 Clear。Clear 不会删除错题本或历史记录。

套题做到一半、切换 Part 或回看时需要注意什么？

套题切换 Next / Previous 时会保存当前 Part 的作答和高亮；回看历史记录时，会打开对应那一次，不会自动变成最新一次。

套题中提交的每个 Part 也会形成对应单篇的正式记录；首页会在单篇和套题记录中按时间显示最近一次，旧记录仍会保留。

套题做题时原文精听通常不可打开，音频也会更接近考场状态；回看时可以查看原文精听，“查看解析”会同步跳到对应字幕和音频位置。

保存答题记录、导入答题记录、清空全部记录分别是什么？
  • 保存答题记录：导出当前本机数据，适合更新版本或换电脑前备份。
  • 导入答题记录：把之前导出的记录恢复到当前软件。
  • 清空全部做题记录：删除正确率、错题本、套题历史和待完成草稿。

清空全部记录前建议先导出备份；Clear 和“清空全部做题记录”不是同一个功能。

刷题建议
如何刷最高效？有优先级吗？

先找到自己的薄弱 Part，对应练习。硬要排序的话，可以从高频和最新题开始刷，但不代表非高频一定不考。

最重要的不是刷了多少题，而是能不能复盘、总结错误，并避免重复犯同一个错误。

只刷高频可以吗？

不太建议。如果只是抱着刷到原题的心态来用，这份资料可能不适合你。它更适合用来提升听力能力、熟悉考场难度，而不是依赖所谓押中。

难度怎么样？和剑雅差距大吗？

难度是随机的，和真实考试一样会有波动。有些题简单，有些题会比较难，分数上下浮动 0.5-1 分都很正常。

做题结果不等于最终考试分数，更应该关注自己有没有听力能力上的提升。

只刷你的题，不刷剑雅可以吗？

不推荐。剑雅是不可替代的基础素材。只有当剑雅已经刷完、甚至答案都记住了，再用这些题作为补充会更合适。

需要倍速听吗？

不需要。音频是考场原速，我也不推荐平时一上来就倍速。原速有原速的节奏、气口和信息推进方式。

复盘、精听或已经很熟悉之后，可以适当倍速回顾结构，但正常做题建议原速。

答案、原文与题目问题
答案、原文、解析在哪里？

答案一般在 PDF 最后一页，HTML 会自动批改。答案不一定唯一，一切以 PDF 为准。

原文在 HTML 右下角点击 Transcript 查看；如果有单独的 transcript 文件，可以用文本编辑器打开。

普通版基本无完整解析，主要看原文校对；VIP 群里有带练视频和讲解。

答案或题目有问题怎么办？

答案偶尔可能有争议，有问题我一般会在小红书说明。题目问题大多来自代码生成或 AI 识别 bug，也会尽量更新说明。

部分机经题本身可能存在不合理或牵强之处，适合作为练习，但不建议过度纠结。

联系与入群问题
如何找到你？

名字一直是：Listening永不虾滑。可以多搜索一下。群介绍里会放最新群号。设置入群问题主要是为了避开机构、引流和倒卖。

能不能快一点通过？大概多久？

一般 24 小时内会处理，但没有固定时间。我没办法一直盯着消息，也不会因为私信催促就更快通过，通常会按申请顺序处理。

为什么申请好几次还是没通过？

常见原因有：

  • 账号等级太低、无内容，可能被判断为风险账号。
  • 入群问题填写错误，需要的是号码，不是名字。
  • IP 出现风险提示，系统不允许添加。
  • 申请被系统吞掉，海外或反复申请时可能发生。
  • 加的是已满群，满 500 人的群无法再进新人。避开 500 的整数倍群号。
